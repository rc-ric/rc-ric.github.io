# RCRIC Website:

Official website for **Rajuk College Robotics & ICT Club (RCRIC)**.

## Tech Stack:

- `HTML5`
- `CSS3` (custom styling and animations)
- `JavaScript` (UI behavior, observers, interactive effects)
- `Tailwind CSS` via CDN
- Google Fonts (`Orbitron`, `Space Mono`)

## Run Locally:

### Prerequisites:

- `Node.js` and `npm`

### Setup:

```bash
npm install
```

### Start Local Server:

```bash
npm start
```

This uses the `serve` package defined in `package.json` and serves `index.html` for local preview.
