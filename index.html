Activities

// workshops

Weekly Workshops

Hands-on sessions every week covering PCB design, ROS2, computer vision, SLAM, and embedded systems. Learn by building.

// bootcamps

Technical Bootcamps

Intensive multi-day bootcamps during breaks. Deep dives into advanced topics like machine learning, autonomous navigation, and system integration.

// fabrication

Mechanical Design

Master CAD software, 3D printing, CNC machining, and laser cutting. Design real robot chassis, enclosures, and mechanical systems from scratch.

// programming

Embedded Systems

Write firmware in C++ and Python for microcontrollers. Work with ROS2, Arduino, Raspberry Pi, and real-time control systems.

// competition

Competitions

Compete in FIRST Robotics, VEX, RoboCup, and other national robotics competitions. Test your skills against the best teams.

// projects

Team Projects

Collaborate on multi-month projects. Learn version control, system integration, testing, and professional engineering workflows.
